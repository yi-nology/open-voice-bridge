系统权限与服务

        
网页本身以普通用户运行；只有下面这个 root 助手拥有额外权限。

      
    
        
  • xiaomi-remote-remap.service（root）：Go 按键 remapper，独占遥控器 evdev 并通过 uinput 注入映射按键。
    • 
        
  • xiaomi-remote-go.service（用户）：Go agent，负责 BLE/ATVV、ASR、PipeWire 和网页 UI，监听 127.0.0.1:8787。
    • 
        
  • 开机自启：用户 agent 通过 systemd + linger 在登录前启动，root remap 随系统启动；xiaomi-remote doctor 可检查启用状态。
    • 
        
  • keyd.service / xiaomi-remote-helper.service（旧实现，已停用，保留回退）。
    • 
        
  • xiaomi-mic.service / xiaomi-remote-ui.service（旧 Python 版，已停用，保留回退）。
    • 
      

      
    
        
  • 蓝牙：系统设置 → 隐私与安全性 → 蓝牙，允许运行 agent 的宿主（终端或 launchd）连接遥控器。
    • 
        
  • 辅助功能：粘贴识别结果需要合成 ⌘V，授予运行该二进制的宿主；未授权时字幕与历史照常，只是不会自动上屏。
    • 
        
  • 按键映射不适用：evdev/uinput 是 Linux 原语，macOS 上按键走遥控器原生 HID，不注入。
    • 
        
  • 虚拟麦克风不适用：macOS 需要 AudioServerPlugin 才能造虚拟麦，v1 直接把解码样本喂给 ASR。
    • 
        
  • 开机自启：用 launchd 或终端手动运行 xiaomi-remote agent；xiaomi-remote doctor 检查遥控器与权限。
    • 
      

      

        ASR provider 可在侧边栏「语音识别」中编辑并热切换，也可直接修改
        ~/.config/xiaomi-remote/config.json 的 asr 段；
        支持 MiMo、OpenAI 兼容接口、本地 whisper.cpp 和任意本地命令，并可配置 fallback 链。
      

      

        捕获模式会暂停按键注入并独占遥控器设备，因此捕获期间按键只显示、不进入桌面；电源键也安全。结束捕获或关闭网页后会自动恢复映射。

遥控器设备

          
管理已配置的遥控器，选择当前语音设备；按键 remap 会同时接入所有启用的设备。已在系统蓝牙中配对并连接遥控器后，再点“扫描已连接设备”。

          
支持小米蓝牙遥控器 1 / 2 / 2 Pro（ARN9 / RC001-MS / RC003-MS）；Google / Android TV / Fire TV / NVIDIA 等 ATVV 遥控器可选 Generic ATVV（部分型号会自动推荐）；Apple Siri Remote 1 代（A1513 / A1962）可选 Apple Siri Remote，目前仅按键，不含 Siri 语音。
