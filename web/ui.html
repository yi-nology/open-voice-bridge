文本注入（自动上屏）

      
识别结果通过键盘事件写进当前焦点窗口。如果出现「识别是对的、上屏却是数字或乱码」，把注入通路切成 X11 即可。

      

        
        
      

      
切换注入通路后需要重启服务：systemctl --user restart xiaoyao.service

系统权限与服务

        
网页本身以普通用户运行；需要额外权限的只有一个：xiaoyao-remap.service（按键映射助手）。

      
    
        
  • 按键映射助手 — 你要做的：sudo make install-remap。装好后它以 root 接管遥控器按键并注入映射结果；没有它语音听写照常，只是自定义键位不生效。
    服务名 xiaoyao-remap.service（root）。
    • 
        
  • 听写服务 — 你要做的：sudo make install-user（或登录前自启）。它负责遥控器连接、识别、虚拟麦克风和本页，监听 127.0.0.1:8787。
    服务名 xiaoyao.service（普通用户）。
    • 
        
  • 开机自启检查 — 运行 xiaoyao doctor，每条缺口都会给出可执行的修复命令。
    • 
        
  • 旧实现（keyd.service、xiaomi-mic.service 等）已停用，仅保留回退记录。
    • 
      

      
    
        
  • 蓝牙 — 你要做的：系统设置 → 隐私与安全性 → 蓝牙，允许运行本服务的宿主（终端或 launchd）连接遥控器。
    • 
        
  • 辅助功能 — 你要做的：同一处「辅助功能」里授权，识别结果才能自动上屏；不授权也能用——字幕与历史照常，只是不自动粘贴。
    • 
        
  • 按键映射不适用 — macOS 上按键走遥控器原生 HID，不注入，无需任何设置。
    • 
        
  • 虚拟麦克风不适用 — 识别直接消费遥控器音频，其它应用听不到虚拟麦，无需任何设置。
    • 
        
  • 开机自启 — 你要做的：用 launchd 或终端运行 xiaoyao agent；xiaoyao doctor 会检查遥控器与权限。
    •

遥控器设备

          
管理已配置的遥控器，选择当前语音设备；按键 remap 会同时接入所有启用的设备。已在系统蓝牙中配对并连接遥控器后，再点“扫描已连接设备”。

          
支持小米蓝牙遥控器 1 / 2 / 2 Pro（ARN9 / RC001-MS / RC003-MS）；Google / Android TV / Fire TV / NVIDIA 等 ATVV 遥控器可选 Generic ATVV（部分型号会自动推荐）；Apple Siri Remote 1 代（A1513 / A1962）可选 Apple Siri Remote，目前仅按键，不含 Siri 语音。
